# ArtDex · 一刻 (A Moment) — 设计稿

- **日期**: 2026-06-15
- **分支**: `feat/a-moment`
- **状态**: 设计定稿,待落实施计划

---

## 1. 核心理念

> 拍卖会用**钱**买**画的所有权**;ArtDex 用**在场**换**一刻的所有权**。
> 用户拥有的不是画,是**他和它共处过的、不可伪造、永不消失的那一刻**。

这是对拍卖逻辑的正面对立:

| | 获取方式 | 谁能拥有 | 拥有之后 |
|---|---|---|---|
| **拍卖会** | 钱 → 占有实物 | 少数人,排他 | 关系**终结**(画进保险库) |
| **ArtDex** | 在场 → 占有一刻 | 所有人,平等 | 关系**在生长**(邮戳叠越攒越厚) |

富人能反复花钱买画;但"第一次站在真迹前"这件事谁都只能拥有一次,且**买不来、不可快进**。

---

## 2. 决策记录(已拍板,含理由)

| 决策 | 选择 | 理由 |
|---|---|---|
| 拥有是否会褪色 | **永不褪色** | 现实中到访次数有限,褪色=惩罚真实经历,只带来失落 |
| 珍贵感来源 | **不可重复**(而非消失) | 用"唯一的一次"造珍贵,是期待不是损失 |
| 同画可封缄几次 | **可多次,初遇为尊** | 第一枚=「初遇」(镶金),其余=「重逢」;允许人生不同阶段重新相遇 |
| 铸造动作 | **A 拍下 + C 郑重标记** | 否掉 B 凝视计时(无法量化、会变任务) |
| 显影时长 | **10–20 秒** | 真宝丽来手感;够"等一下"的仪式,但不折磨 |
| 识别与合影 | **先认后拍**(拆成两步) | 解决"合影遮挡画作无法验证"的问题 |

---

## 3. 核心流程:封缄 → 显影

铸造一刻分两步,**识别**与**纪念**互不干扰:

| 步骤 | 干什么 | 需要看清画 |
|---|---|---|
| ① 见证 / 识别 | 确认"就是这幅真迹",锁定作品身份 | **要**(干净视角) |
| ② 纪念 / 合影 | 留下用户在场的私人画面 | **不要**(随便挡) |

### 3.1 流程
1. **认画**:用户举起手机对准画(此刻还没入镜),App 认出它 → 锁定 `artworkId`。这一步即"见证"。
2. **入镜封缄**:认出后,用户走进画面(贴脸自拍、挡住大半都行),**按住屏幕约 1 秒**,松手即封缄。
3. **显影**:得到一张**雾蒙蒙的宝丽来**,10–20 秒内由模糊渐清。显影中只能瞥见轮廓,勾着惦记。
4. **成型**:显好后照片居中,四周盖上 **地点 · 日期 · "你在此见证"** 的印戳。永久,不褪色。

### 3.2 识别兜底链(保证各种馆都能用)
1. **AI 视觉识别**:对准画自动认出(复用 App 已有的 Bedrock 识别底子)。
2. **本馆在展清单点选**:认不出时,从该馆当前在展作品里点选(后端已有 museum↔artwork 展览数据,**永远兜得住**)。
3. (暂不做)扫墙签 QR——依赖馆方支持。

## 4. 数据模型

把当前"一画一藏品"升级为"**一画一叠时刻**"。

```
Moment {
  id:         string        // 唯一
  artworkId:  string        // 来自识别步骤
  museumId:   string        // 识别时所在馆
  capturedAt: number        // 封缄时间戳(决定 初遇/重逢 顺序)
  photo:      string        // 用户合影(纪念,不参与验证)
  kind:       "first" | "reunion"   // 该 artwork 最早一枚为 first
  location?:  { lat: number; lon: number }  // 可选出处戳
}
```

- 某 artwork 的 `kind="first"` = 其名下 `capturedAt` 最小的那枚(「初遇」,镶金边)。
- 「重逢」= 同一 artwork 的后续每一枚。
- **显影态**:`capturedAt + ~15s` 之前为 *developing*,之后为 *developed*(可由时间戳推导,无需额外字段)。

> 注:这是对现有 `collected: Record<artworkId, {selfie}>` 的结构性改动——从"每画一条"变为"每画一组"。读 `collected` 的地方(Dex、地图、成就、排行榜)都需相应适配。这是本次"较大改动"的主体,详细迁移步骤留给实施计划。

## 5. 对现有 App 的改造

- **Capture 页**:从"拍照打卡"升级为「**先认 → 封缄 → 显影**」仪式。
- **作品详情**:展示该画的**邮戳叠**——「初遇」置顶镶金,「重逢」按时间排列,呈现一段"你和它的时间线"。
- **地图**(缩放已完成 ✅):图钉数字 = 你封缄过的"刻"数;金钉 = 你拥有某画的「初遇」。

---

## 6. 在场如何被见证(轻验证)

"不可伪造"是叙事底气,但这是**个人纪念**而非竞技排行,故采轻验证:

- **必须当场实拍**(不能从相册导入)。
- **可选**盖上地理位置戳作为出处。
- **不做**强 GPS 围栏 / 防作弊——骗这个系统的人,骗的只是他自己。

---

## 7. 明确不做(YAGNI)

- ❌ 褪色 / 过期
- ❌ 凝视计时(无法量化,会变任务)
- ❌ 稀有度拖慢显影(10–20s 内无意义)
- ❌ 强 GPS 围栏 / 反作弊系统
- ❌ 墙签 QR 扫描(依赖馆方,先不做)
